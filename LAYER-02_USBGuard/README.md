# USBGuard Safe Authorizer
## Zero-Trust USB Device Authorization Framework

| ENGLISH | TÜRKÇE |

| # 🛡️ USBGuard Zero-Trust Manager (Enterprise-Grade)<br><br>Can a simple USB flash drive, mouse, or keyboard compromise your system? Absolutely. BadUSB and Rubber Ducky attacks disguise malicious payloads within innocent hardware.<br><br>This script hardens USBGuard with a **Zero-Trust** philosophy: nothing is trusted by default, everything is verified, and authorization requires human consent.<br><br>## ✨ Why This Script?<br><br>* **Hardware 2FA:** Verifies cryptographic Hash + physical Topological Port before trust.<br>* **Temporary-First:** Never grants permanent access immediately. Test first, seal later.<br>* **Race Condition Hardened:** Kernel-level atomic locks (`flock`) prevent split-brain corruption.<br>* **SELinux Aware:** Preserves file contexts, zero AVC denials.<br>* **Thermal Protection:** Pauses if Surface Pro 9 exceeds 75°C.<br>* **1000 Runs = Same Result:** Fully idempotent design. | # 🛡️ USBGuard Sıfır-Güven Yöneticisi (Kurumsal Seviye)<br><br>Sıradan bir USB bellek bilgisayarınızı ele geçirebilir mi? Evet. BadUSB ve Rubber Ducky saldırıları zararlı yazılımları masum donanıma gizler.<br><br>Bu betik USBGuard'ı **Sıfır-Güven** felsefesiyle sertleştirir: hiçbir şey varsayılan olarak güvenilmez, her şey doğrulanır, yetkilendirme insan onayı gerektirir.<br><br>## ✨ Neden Bu Betik?<br><br>* **Donanımsal 2FA:** Güvenmeden önce kriptografik Hash + fiziksel Port doğrulaması.<br>* **Önce Geçici İzin:** Asla anında kalıcı izin vermez. Önce test et, sonra mühürle.<br>* **Yarış Durumu Korumalı:** Çekirdek seviyesi atomik kilitler (`flock`).<br>* **SELinux Uyumlu:** Dosya bağlamlarını korur, sıfır AVC reddi.<br>* **Termal Koruma:** Surface Pro 9 75°C'yi aşarsa duraklar.<br>* **1000 Kere Çalışsa Aynı Sonuç:** Tamamen idempotent tasarım. |
| 🛠️ Usage | 🛠️ Kullanım |
| **Event-Driven** — Only run when you plug in a new blocked USB device:<br><br>```bash<br>sudo usb-authorize.sh<br>```<br><br>1. Blocked devices list appears.<br>2. Enter the device **ID number**.<br>3. Temporary permission? → `yes`<br>4. Test your device.<br>5. Permanent seal? → `PERMANENT` (all caps!)<br><br>⏱️ 60-second timeout on every prompt. No idle auto-approval. | **Olay Güdümlü** — Sadece yeni takılan USB cihaz engellendiğinde çalıştırın:<br><br>```bash<br>sudo usb-authorize.sh<br>```<br><br>1. Engellenen cihazlar listelenir.<br>2. Cihaz **ID numarasını** girin.<br>3. Geçici izin? → `yes`<br>4. Cihazınızı test edin.<br>5. Kalıcı mühür? → `PERMANENT` (büyük harf!)<br><br>⏱️ Her soruda 60 saniye zaman aşımı. Başıboş onay yok. |
