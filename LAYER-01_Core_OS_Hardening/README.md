# 🛡️ Aegis Layer-01 Engine: Core OS Hardening & Extreme Tuning

Enterprise-Grade Kernel Integrity, Cryptographic Time, and Architectural Hardware Stabilization for Fedora Workstation

| ENGLISH | TÜRKÇE |
| :--- | :--- |
| **Overview**<br>The **Aegis Layer-01 Engine** is a military-grade post-install hardening and extreme tuning framework engineered specifically for Fedora Workstation environments (heavily optimized for mobile Intel Core architecture like the Microsoft Surface Pro 9). Operating under the ruthless tactical philosophy of *"Zero-Assumption"* and *"Do Not Guess, Verify"*, this layer acts as the absolute bastion of the operating system. It completely re-architects kernel-space memory allocation, seals the network stack against asymmetric attacks, implements cryptographic timestamp binding, and injects secure hardware subsystem definitions without pushing your hardware to its thermal throttling boundaries. | **Genel Bakış**<br>**Aegis Birinci Katman Motoru**, Fedora Workstation işletim sistemi ortamları için özel olarak tasarlanmış (Microsoft Surface Pro 9 gibi mobil Intel Core mimarileri için optimize edilmiş), askeri düzeyde bir çekirdek sıkılaştırma ve ekstrem optimizasyon çerçevesidir. *"Sıfır Varsayım"* ve *"Tahmin Etme, Doğrula"* siber savunma doktrini altında çalışan bu katman, işletim sisteminin bel kemiğini koruma altına alır. Çekirdek bellek alanlarını (kernel space) yeniden yapılandırır, ağ yığınını asimetrik saldırılara karşı zırhlandırır, tahrif edilemez kriptografik zaman damgaları mühürler ve donanımı termal darboğaza (thermal throttling) sokmadan harici portları udev seviyesinde dış dünyaya kapatır. |
| **Enterprise-Grade Architecture**<br>- **01a: Kernel Sysctl & TCP BBR:** Eradicates wireless *Bufferbloat* by discarding reactive congestion algorithms. Deploys TCP BBR combined with Fair Queueing (`fq`) to model bottlenecks, restricts `ptrace_scope`, and blinds unprivileged eBPF JIT access.<br>- **01b: Cryptographic Time (NTS):** Enforces Network Time Security (NTS) over TLS 1.3 via Port 4460 to intercept Man-in-the-Middle (MitM) or time-skew attacks, creating an untampered epoch anchor for AIDE and Auditd.<br>- **01c: Core Security Baseline (BLS):** Employs the Boot Loader Specification (`grubby`) to embed critical parameters (`init_on_alloc=1`, `lockdown=integrity`) into all active kernels while injecting secure execution boundaries (`hidepid=2`) inside `fstab`.<br>- **01d: Hardware Subsystem Seals:** Natively orchestrates Intel Hardware P-States (HWP) and EPP profiles, replacing dangerous runtime hooks with static Udev Subsystem Driver Seals to intercept malicious physical DMA blocks (BadUSB, O.MG cables). | **Kurumsal Düzey Mimari**<br>- **01a: Çekirdek Parametreleri ve TCP BBR:** Kablosuz ağlardaki *Bufferbloat* (tampon bellek şişmesi) krizini yok etmek için reaktif algoritmaları eler. TCP BBR ve `fq` qdisc ile ağ darboğazlarını modeller, `ptrace_scope` yetkilerini kısıtlar ve eBPF JIT derleyicisini dış dünyaya kör eder.<br>- **01b: Kriptografik Zaman (NTS):** Ortadaki Adam (MitM) ve zaman kaydırma saldırılarını engellemek için Port 4460 üzerinden TLS 1.3 tabanlı NTS protokolünü devreye alır; AIDE ve Auditd için tahrif edilemez adli bir zaman damgası zemini hazırlar.<br>- **01c: Güvenlik Baseline ve BLS Mühürleyici:** `grubby` motoru vasıtasıyla tüm BLS girdilerine katı çekirdek parametrelerini (`init_on_alloc=1`, `lockdown=integrity`) çakarken, `fstab` içerisine `hidepid=2` ve güvenli montaj sınırları enjekte eder.<br>- **01d: Donanım ve ACPI Alt Sistem Kalkanları:** Intel dononımsal HWP ve EPP arabirimlerini orkestre eder. Dinamik scriptler yerine statik Udev Sürücü Mühürleri yerleştirerek sisteme fiziksel olarak sızabilecek zararlı DMA donanımlarını (BadUSB, O.MG) kullanıcı alanına geçmeden imha eder. |
